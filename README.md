# Fast Log Streamer 



A high-performance, zero-copy, $O(1)$ memory stream parser for ultra-large log files, built entirely with Python's standard library.



This project is engineered to process multi-gigabyte, billion-line Nginx/Envoy access logs efficiently. By avoiding heavy third-party dependencies (like Pandas or Spark) and regular expressions, it extracts maximum I/O and computing performance from single-machine multi-core architectures.



##  Key Features



* **`mmap` Zero-Copy Streaming**: Completely bypasses Python's traditional `readline` buffer. By mapping the disk file directly into the virtual memory space (`mmap.ACCESS_READ`), it achieves kernel-level page cache slicing for ultimate read speed.

* **Constant $O(1)$ Memory Footprint**: Keeps heap memory usage strictly below 20MB, regardless of whether the log file is 100MB or 100GB. The memory graph remains a perfectly flat line.

* **Regex-Free Byte Slicing**: Rejects slow regular expressions. It utilizes fixed-position binary byte slicing (`Byte Slicing`) to extract time windows in constant time, minimizing CPU overhead per core.

* **Reverse Seek Line Alignment**: Implements a robust multi-processing split-and-merge architecture. Each worker executes a `f.seek()` to a coarse chunk boundary, then scans backward for `\n` to automatically calibrate the record boundary. This ensures zero data loss and zero duplicate processing across worker boundaries.



##  Benchmark



Tested on a multi-core local machine environment, parsing **1,000,000 lines (~90MB)** mock Nginx access log generated by `gen_logs.py` using 20 parallel worker processes:

* **Total Lines Processed**: 1,000,000 Lines
* **Execution Time**: ~0.5 Seconds
* **Peak Traffic Window**: `14:00` accurately detected (100% match with the pre-configured distribution weight)

*Note: Due to fixed multiprocessing fork overhead, the throughput (Lines/Sec) scales up aggressively as the file size increases.*



##  Quick Start



1. Clone the repository and enter the directory:
```bash
git clone https://github.com/MyStiA-LoReLA/log-streamer.git
cd log-streamer
```

2. Run the mock log generator to create 1,000,000 lines of standard Nginx logs (occupies only ~90MB disk space):
```bash
python gen_logs.py
```
3.Launch the core streaming parser to witness the blazing fast multi-processing throughput:
```bash
python log_parser.py nginx_access.log 20
```
